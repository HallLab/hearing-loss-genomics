# Provenance

Which files were copied into this folder rather than produced in it, and the verification
that they arrived intact. Generated by reading the disk, not written by hand.

**Commit at copy time:** `c80bf0f`

SHA-256 over the first 64 MB, which is enough to tell a transfer error from an intact file.
The artifacts SAIGE consumes were additionally compared byte for byte with `cmp`. MD5 is
unavailable on this host, which runs in FIPS mode.
